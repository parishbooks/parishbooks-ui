# @parishbooks-ui/design-system

Shared shadcn/ui (base-maia), theme providers, and global Tailwind styles for all ParishBooks web apps.

Import examples:

```tsx
import { Button } from '@parishbooks-ui/design-system/ui/button';
import { cn } from '@parishbooks-ui/design-system/utils';
import '@parishbooks-ui/design-system/styles/globals.css';
```

Add components with the CLI from `apps/parishbooks-client-ui` (`components.json` points here).
